# Alien 51: Escape Mission
You are an alien whose mission is to take advantage of a guard’s distraction to escape from Area 51 — but be careful, along the way you’ll encounter several threats that won’t make things easy for you. 

Dive into this game inspired by The Binding of Isaac and Enter the Gungeon, where you’ll progress through a labyrinthine laboratory, collecting items and searching for upgrades to enhance your character. 

The game supports both English and Spanish. 

This is a project I created for my final degree assignment. In the end, I really liked how it turned out, and rather than letting it fade into oblivion, I decided to publish it so more people can play it.
